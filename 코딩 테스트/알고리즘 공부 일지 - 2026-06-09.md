## 발생한 문제 & 해결 방법
### 문제 상황
- 정수 배열 `arr`와 2차원 정수 배열 `queries`이 주어집니다. `queries`의 원소는 각각 하나의 `query`를 나타내며, `[s, e, k]` 꼴입니다.

각 `query`마다 순서대로 `s` ≤ `i` ≤ `e`인 모든 `i`에 대해 `k`보다 크면서 가장 작은 `arr[i]`를 찾습니다.

각 쿼리의 순서에 맞게 답을 저장한 배열을 반환하는 solution 함수를 완성해 주세요.  
단, 특정 쿼리의 답이 존재하지 않으면 -1을 저장합니다.

- 인덱스 범위 지정에서 계속 의도와 다른 값이 나옴

### 해결 방법
- **범위 연산자:** `arr.begin() + v[1]`은 `v[1]` 인덱스를 포함하지 않음 `arr.begin() + v[1] + 1`로 수정

### 헷갈렸던 점
- `begin() + end`를 하면 마지막 요소가 포함될 줄 알았는데, 실제로는 끝 인덱스 이전까지만 포함된다는 점이 혼동
- `Temp = numLog[i] - Temp;`와 같이 루프를 돌 때마다 변수를 업데이트 하면 기준값변한 다는 점을 간과
	- 상태를 누적시키지 말고, `numLog[i-1]`과 같은 기존 데이터를 직접 활용 으로 해결


### 예제 코드 또는 상황
## CPP
```cpp
// 필요한 경우 코드 작성

vector<int> solution(vector<int> arr, vector<vector<int>> queries) {
    vector<int> answer;
    
    for(auto v: queries )
    {
        //쿼리 대로 슬라이스
        
        vector<int> Temp(arr.begin()+v[0],arr.begin()+v[1]+1);
        
        // v[2] 보다 큰 애들 Temp2에 넣기
        vector<int> Temp2;
        for(auto T : Temp)
        {
            if(T > v[2])
            {
                Temp2.push_back(T);
            }
        }
        if(Temp2.empty())
        {
            answer.push_back(-1);
        }
        else
        {
            //Temp2의 첫번째 값 을 초기 값으로 지정
            int Small = Temp2[0];
            for(auto T2 : Temp2)
            {
                if( Small > T2)
                {
                    Small = T2;
                }
            }
            answer.push_back(Small);
        }
        
    }
```
