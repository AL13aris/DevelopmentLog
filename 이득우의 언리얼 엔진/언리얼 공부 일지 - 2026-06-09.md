### 배운 점
- 언리얼 엔진에서 컴포지션 구현 방법
	- 1. CDO에 미리 언리얼 오브젝트를 생성해 조합한다 CreateDefaultSubobject() (필수 포함)
	- 2. CDO에 빈 포인터만 넣고 런타임 에서 언리얼 오브젝트를 생성해 조합한다 NewObject() (추가적인 옵션)
- 컴포지션 관계에 있는 애들은 class 전방 선언을 해주면 의존성을 최대한 없앨 수 있다 언리얼 엔진5 부터는 TObjectPtr로 구현 할것
``` cpp
  TObjectPtr<class UCard> Card;
```

- 레퍼런스로 반환을 하고 있으면 const를 쓸때 둘다 반환 해야 할것
- 부모 클래스에 컴포지션 생성을 했으면 자식에게는 생성 하지 말것
  대신 Get Set 함수로 세팅 할 것
```cpp
Card = CreateDefaultSubobject<UCard>(TEXT("NAME_Card"));
```
