### 발생한 문제 & 해결 방법

### **문제 상황**
- `SaveGameStarizon.h`: No such file or directory
- WorldTimeSubsystem에서 C3668 (override 지정자가 기본 클래스 메서드를 재정의하지 않음)
- StarizonGameInstance.cpp에서 C2065 (`UWorldTimeSubsystem` 선언되지 않은 식별자)
- LNK2001 (`SaveSlotName` 확인할 수 없는 외부 기호)
- 클래스 생성 시 이름을 잘못 입력해서 `UUStarizonGameInstance`로 생성됨

### **해결 방법**
- include 경로 문제 → `#include "SystemManager/SaveGameStarizon.h"`처럼 서브폴더 경로 명시
- override 에러 → `WorldTimeSubsystem`이 `FTickableGameObject`를 다중 상속해야 하는데 빠져 있었음. `class UWorldTimeSubsystem : public UGameInstanceSubsystem, public FTickableGameObject`로 수정 + `#include "Tickable.h"` 확인
- 선언되지 않은 식별자 → `.cpp`에 `#include "WorldTimeSubsystem.h"` 누락, 추가로 해결
- LNK2001 → 헤더에 `static const FString SaveSlotName;` 선언만 있고 `.cpp`에 정의가 없었음. `.cpp` 최상단에 `const FString UStarizonGameInstance::SaveSlotName = TEXT("StarizonAutoSave");` 추가
- 클래스 이름 오타 → UE가 UObject 계열엔 자동으로 `U`를 붙이므로, 생성 시 이름은 접두사 없이 입력해야 함 (`StarizonGameInstance`)

### **배운 점**
- UE C++ 에러는 몇 가지 패턴(include 누락, override 불일치, static 멤버 정의 누락)이 반복된다는 걸 체감함
- Binaries/Intermediate는 자동 재생성되지만, 직접 넣은 외부 파일(llama.cpp 관련 dll 등)은 재생성 대상이 아니므로 삭제 전 반드시 백업 필요

### 오늘 배운 점 (TIL)
### **알게 된 내용:**
- `USaveGame` 기반 자동저장 흐름: `SaveToSlot()`(멤버 → SaveObj)과 `LoadFromSlot()`(SaveObj → 멤버)이 정확히 대칭 구조라는 것
- `GetSubsystem<T>()`로 다른 서브시스템(`WorldTimeSubsystem`)의 데이터를 GameInstance에서 가져오는 패턴
### **헷갈렸던 점**
- `SetCurrentDay()`를 호출할 때 `Time->`를 안 붙이고 그냥 호출하려 했던 것 — 어떤 객체의 함수인지 명시해야 한다는 걸 놓침
- 델리게이트(`OnPlayerLevelChanged`)를 새로 선언하려 했던 것 — 이미 헤더에 있는 멤버를 그냥 `.Broadcast()`로 호출하면 된다는 걸 처음엔 몰랐음
**예제 코드 또는 상황**

cpp

```cpp
// .h — 필요한 경우 코드 작성
// .h — StarizonGameInstance.h (일부) 
UFUNCTION(BlueprintCallable, Category = "Save") bool LoadFromSlot();
```

cpp

```cpp
// .cpp — 필요한 경우 코드 작성
bool UStarizonGameInstance::LoadFromSlot() 
{ 
USaveGameStarizon* SaveObj = Cast<USaveGameStarizon>( UGameplayStatics::LoadGameFromSlot(SaveSlotName, /*UserIndex=*/0)); 

if (!SaveObj) return false; 

if (UWorldTimeSubsystem* Time = GetSubsystem<UWorldTimeSubsystem>()) 
{ 
	Time->SetCurrentDay(SaveObj->CurrentGameDay); 
} 
MerchantLevel = SaveObj->MerchantLevel; 
MerchantExp = SaveObj->MerchantExp; 
CombatLevel = SaveObj->CombatLevel; 
CombatExp = SaveObj->CombatExp; 
LastPortID = SaveObj->LastPortID; 


OnPlayerLevelChanged.Broadcast(); return true; 
}
```
