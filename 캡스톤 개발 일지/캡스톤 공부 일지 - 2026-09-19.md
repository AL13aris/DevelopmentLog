### 기본 정보

- 날짜: 2026-09-19 (한국시간)
- 프로젝트: Starizon Light / GameCapstone
- 기록 성격: 수정·Editor 빌드 확인·계획

### 오늘 한 작업

- **코드 구현** — ApplyExp의 경험치 인자를 값 전달(int32 Exp)에서 참조 전달(int32& Exp)로 바꿔 MerchantExp와 CombatExp 멤버에 누적 및 레벨업 후 잔여 경험치가 반영되게 했다.
- **규칙 유지** — 필요 경험치 100×현재 레벨, 초과 경험치 이월, 다중 레벨업, 0 이하 지급 무시와 레벨 변경 알림은 유지했다.
- **빌드 실행** — 사용자 명시 요청과 에디터 종료 확인 후 GameCapstoneEditor Win64 Development 전체 Editor 빌드를 수행했다.
- 3주 베타 기획서에 통합 목표와 기능별 확인 과제를 정리했다. 일정·완료 조건은 계획이며 각 기능의 구현 완료로 계산하지 않았다.

### 발생한 문제 & 대응

- ApplyExp 내부에서 경험치가 바뀌어도 원래 멤버에 반영되지 않는 값 전달 오류가 있었다.
- LandscapeCombinator/프로젝트의 StructUtils 의존성에 deprecated 경고가 있었으나 이번 수정의 컴파일 오류는 아니었다.

### 확인 결과와 검증 범위

- **빌드 확인** — 종료 코드 0, Result: Succeeded, UBT 총 10.52초, UHT 및 9개 작업 완료. StarizonGameInstance.cpp 컴파일과 UnrealEditor-GameCapstone.dll 링크 성공.
- **미검증** — PIE의 경험치 지급 순서, 레벨업 알림과 저장·로드 후 누적 경험치 보존은 당일 확인하지 않았다.

### 당시 남은 문제 / 미확인 사항

- Editor 빌드 성공은 Shipping 패키징이나 인게임 경험치 흐름 검증을 뜻하지 않는다.
- 경험치 지급량과 자동 저장 시점은 변경하지 않았다.

### 다음 작업 — 당시 기준

- 상인·전투 각각 1레벨/경험치 0에서 30→40→40 지급 시 (1,30)→(1,70)→(2,10)인지 확인한다.
- 650 지급 시 (4,50), 0/음수 지급 무시, 명시 저장 후 로드 유지 여부를 시험한다.
- 계획에 적은 통합 시험을 실제 게임 화면과 저장 결과로 확인하고 진행 상태를 갱신한다.
