## 개발 일지 & TIL

**Perforce 원본을 보존하는 Graft 코드 탐색 구성**

[[00_캡스톤 제작 기록 - 2026년 9월~11월|← 날짜별 제작 기록 목차]]

### 기본 정보

- 날짜: 2026-09-23 (한국시간)
- 프로젝트: Starizon Light / GameCapstone
- 기록 성격: 개발 도구 구성

### 오늘 한 작업

- Graft 0.19.0과 GameCapstone 전용 탐색 도구를 Perforce 작업 폴더 밖에 설치하고 프로젝트 소스를 읽도록 구성했다.
- 함선·플레이어·전투와 퀘스트·인벤토리·LLM의 연결을 설명하는 한국어 자료를 정리했다. 원본 소스, 설치 도구, 설명·캐시의 위치를 분리했다.
- 시스템 Node를 바꾸지 않고 별도 Node 및 빌드 도구를 사용해 네이티브 파서 설치 문제를 해결했다.

### 발생한 문제 & 대응

- 기존 설치 도구가 Visual Studio 2026을 인식하지 못해 네이티브 파서 설치가 실패했다. 외부 전용 도구로 필요한 파서를 빌드했다.

### 확인 결과와 검증 범위

- 설정 문서의 최초 설정일은 9월 23일이고 이후 변경분 검토일은 9월 24일이다. 현재 문서에 있는 9월 24일 지도 수치를 9월 23일 결과로 소급하지 않았다.

### 당시 남은 문제 / 미확인 사항

- Graft의 C++ 헤더 분석, 리플렉션·델리게이트 호출 그래프에는 누락 가능성이 있다. Content의 BP·DataTable과 실제 PIE 동작은 이 색인만으로 확인할 수 없다.

### 다음 작업 — 당시 기준

- 저장된 설명의 변경 상태를 확인한 다음 검색 결과와 실제 원문을 대조한다.

### 오늘의 기술 정리 (TIL)

- 탐색 도구의 그래프는 코드 위치를 찾는 수단이다. 원문 확인과 런타임 시험을 대신하지 않으며 읽기 전용 Perforce 파일도 분석할 수 있다.
