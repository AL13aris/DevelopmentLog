### 발생한 문제 & 해결 방법

### **문제 상황**
- `APlayerShipPawn` 클래스 선언에서 `public IInteractable`을 상속 목록에 빠뜨림 (`#include`는 했지만 상속만 누락) → `OnInteract_Implementation`에 붙인 `override`가 재정의 대상을 못 찾아 `E1455`, 이어서 `E0094`/`E0077` 연쇄 에러
- `OnAimStateChanged`/`OnAimTrajectoryUpdated`(`BlueprintImplementableEvent`)의 구현부를 실수로 `.cpp`에 직접 작성 → `LNK2005`(기호 중복 정의), `LNK1169`(링크 실패)

### **해결 방법**
- 클래스 선언을 `class APlayerShipPawn : public AShipBase, public IInteractable`로 수정
- `.cpp`에서 두 `BlueprintImplementableEvent` 함수의 정의부를 완전히 삭제 (선언은 헤더에 남기고, 실제 구현은 블루프린트 이벤트 그래프에서 하는 게 맞는 사용법)

### **배운 점**
- `BlueprintNativeEvent`(`_Implementation` 접미사, C++에서 구현)와 `BlueprintImplementableEvent`(C++엔 선언만, 블루프린트에서 구현)는 완전히 다른 매크로 — 후자에 `.cpp` 정의를 작성하면 UHT가 자동 생성한 정의와 충돌해서 링커 에러로 이어짐
- 다중 상속 목록에서 인터페이스 하나를 빠뜨리면, 그 인터페이스 함수에 붙인 `override`가 "재정의 대상 없음"으로 처리되며 뒤쪽 코드 파싱까지 연쇄로 깨뜨릴 수 있음 — `override` 관련 에러(`E1455`)가 뜨면 상속 목록부터 확인

### 위험 요소 / 리팩토링할 부분
- `FireAimedCannon()`의 좌/우 판별(`FVector::CrossProduct(ShipForward, CameraForward).Z >= 0`) 부호가 실제로 맞는지 아직 인게임 검증 안 됨
- 조준 UI(포 궤적선)는 `OnAimStateChanged`/`OnAimTrajectoryUpdated` 이벤트만 C++에서 던져주는 상태 — 실제 궤적 그리기는 블루프린트/위젯 쪽 작업(최민승 담당 UI와 맞물릴 가능성)
- 조준 중에도 배 조향/이동이 그대로 가능한 채로 뒀음 — 조준 중엔 배를 멈추게 할지 여부 아직 미정
- `SailAccelerationRate`(0.5), `AimAdjustRange`(15도), `AimAdjustSpeed`(60) 등 임시값 다수 — 실제 플레이 테스트로 튜닝 필요
- `BP_PlayerShipPawn` 블루프린트 자체가 아직 없음 — 메시/소켓 위치/`ProjectileClass`/Input 항목 전부 미설정
- `IA_Sail`/`IA_Turn`/`IA_FireCannon`/`IA_Aim`/`IA_Anchor`/`IA_Zoom`과 `IMC_Ship`이 에디터에 아직 생성되어 있지 않음

### 오늘 배운 점 (TIL)
### **알게 된 내용:**
- `UBuoyancyComponent`의 정확한 include는 `#include "BuoyancyComponent.h"` (Water 모듈 Public 헤더라 폴더 경로 불필요)
- `BlueprintImplementableEvent`는 C++에 정의부를 작성하면 안 되는 함수 — 선언만 하면 UHT가 자동으로 "블루프린트 구현을 찾아 호출하는" 코드를 생성해줌
- `Possess()` 호출 시 대상 Pawn/Character의 `SetupPlayerInputComponent()`가 자동으로 다시 실행됨 — 그 안에서 `AddMappingContext()`를 호출하는 구조라면 Possess 전환마다 입력 매핑 컨텍스트가 자동으로 재적용됨
### **헷갈렸던 점**
다중 상속 목록에서 인터페이스 하나(`IInteractable`)를 빠뜨렸을 때, 에러 메시지(`E1455`, 이어지는 `E0094`/`E0077`)만 봐서는 원인이 "상속 누락"이라고 바로 짐작하기 어려웠음
**예제 코드 또는 상황**

cpp

```cpp
// .h — 필요한 경우 코드 작성
// 실수 — IInteractable이 상속 목록에서 빠짐 
class GAMECAPSTONE_API APlayerShipPawn : public AShipBase 
{ 
	GENERATED_BODY() 
public: 
	virtual void OnInteract_Implementation(AActor* InstigatorActor) override; 
	// E1455 
};
```

cpp

```cpp
// .cpp — 필요한 경우 코드 작성
// 수정 — 인터페이스 상속 추가 
class GAMECAPSTONE_API APlayerShipPawn : public AShipBase, public IInteractable 
{ 
	GENERATED_BODY() 
public: 
	virtual void OnInteract_Implementation(AActor* InstigatorActor) override; 
	// 정상 
};

```
