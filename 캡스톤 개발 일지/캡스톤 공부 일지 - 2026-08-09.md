### 발생한 문제 & 해결 방법

### **문제 상황**
- 대사가 로드되지 않고 "대화 종료"만 계속 뜸(첫 시도)
- `Ending`/`Ending0` 두 파일이 같은 `quest_id`를 가지고 있어 어떤 관계인지 파악이 안 됨

### **해결 방법**
- "대화 종료"만 뜨는 문제는 코드 작성 후 빌드를 안 하고 PIE를 실행해서 이전 컴파일 상태로 실행된 것이 원인 — 재빌드 후 정상 확인
- `Ending`/`Ending0`는 JSON 내 주석(`"//"` 필드)을 통해 김하선가 "선원 대사로 이어갈지 플레이어 독백으로 이어갈지 팀이 정해달라"고 남긴 것으로 확인 — 같은 장면의 두 가지 화자 버전(대안)이었음. 코드 문제가 아니라 스토리 톤 결정 사항이라 팀 판단으로 플레이어 독백 버전을 채택, 미사용 파일은 삭제하지 않고 보관

### **배운 점**
- 코드를 저장만 하고 재빌드를 안 하면, 에디터가 이전 컴파일 결과로 계속 실행되어 "코드가 반영 안 된 것처럼" 보일 수 있다는 것을 다시 확인함 — 항상 "빌드 → 실행" 순서를 지키는 습관이 필요함
- JSON 데이터 안에 `quest_id`가 같은 두 파일이 있으면, 이건 버그가 아니라 "같은 자리에 들어갈 대안 버전"일 수 있다는 것 — 콘텐츠 파일의 의도를 코드만 보고 판단하지 말고 실제 내용(주석 포함)까지 확인해야 한다는 것
- 시스템(전투 컴포넌트, 인터페이스)을 다 만들어도, 그걸 실제로 사용할 "대상"이 기획서에 빠져있으면 아무리 코드가 완성돼도 기능이 완결되지 않는다는 것 — 시스템 간의 의존 관계를 계속 점검할 필요가 있음

### 오늘 배운 점 (TIL)
### **알게 된 내용:**
- `UGameInstanceSubsystem`은 블루프린트 자식을 만들 수 없어서(항상 C++ 클래스 그대로 사용), 초기 데이터를 채우려면 `Initialize()` 함수 안에서 C++ 코드로 직접 값을 넣는 방식이 실용적이라는 것
- DataTable과 단순 TArray/TMap 중 어느 걸 쓸지는 "디자이너가 직접 편집해야 하는가"와 "구조가 복잡한가"를 기준으로 판단하면 된다는 것 — 단순한 순서 목록 정도는 TArray로 충분
### **헷갈렸던 점**
`quest_id`가 같은 JSON 파일 두 개를 처음 봤을 때 이걸 버그(파일명 실수)로 오해할 뻔함 — 실제로는 같은 장면의 "대안 버전"이었다는 걸 파일 내용을 자세히 보고서야 알게 됨
**예제 코드 또는 상황**

cpp

```cpp

void UMainQuestManager::Initialize(FSubsystemCollectionBase& Collection) 
{ 
	Super::Initialize(Collection); ChapterSequence = 
	{ 
		TEXT("Chapter1_Opening"),
		TEXT("Chapter1_Event01"), 
		TEXT("Chapter1_Event02"), 
		TEXT("Chapter1_Event03"), 
		TEXT("Chapter1_IntermediateStage"), 
		TEXT("Chapter1_Ending") 
	}; 
} 
FString UMainQuestManager::AdvanceToNextStage() 
{ 
	CurrentStageIndex++; 
	return GetCurrentStagePath(); 
}
```

cpp

```cpp
// .cpp — 필요한 경우 코드 작성
// .cpp — AMainQuestNPC가 매니저를 통해 다음 대사로 자동 전환 
if (CurrentLineIndex >= ScriptedLines.Num()) 
{ 
	UMainQuestManager* QuestManager = 
	GetGameInstance()->GetSubsystem<UMainQuestManager>(); 
	if (QuestManager) 
	{ 
		FString NextPath = QuestManager->AdvanceToNextStage(); 
		if (!NextPath.IsEmpty()) 
		{ 
			LoadDialogueFromJson(NextPath); CurrentLineIndex = 0; 
		} 
	} 
	return; 
}
```
