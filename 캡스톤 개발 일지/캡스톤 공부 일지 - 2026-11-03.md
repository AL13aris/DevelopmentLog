**9월 이후 캡스톤 제작 기록 복원과 Obsidian 정리**

### 기본 정보

- 날짜: 2026-11-03 (한국시간)
- 프로젝트: Starizon Light / 캡스톤 제작 기록
- 기록 성격: 날짜별 기록 정리

### 오늘 한 작업

- Obsidian의 기존 개발 일지와 프로젝트 폴더별 작업 기록, 대화의 날짜·사용자 확인, 발표 자료와 검증 산출물을 대조해 9월부터 오늘까지의 기록을 정리했다.
- 기존 9월 6일 일지는 보존하고, 근거가 확인된 이후 날짜의 일지와 월별 목차를 추가했다. 한국시간을 기준으로 날짜를 배정하고 확인되지 않는 날은 채우지 않았다.
- 10월 5일 작업 계획은 작성일인 10월 4일에, 팀원의 UI 작업 7개는 전달일인 10월 7일에 기록했다. 같은 작업의 폴더별 중복 설명은 합쳤다.
- 10월 30~31일 FFTPlugin 작업은 별도 해양 플러그인 개발로 구분하고 GameCapstone에 적용 완료된 것으로 계산하지 않았다.

### 확인 결과와 검증 범위

- 일지는 구현, 설계, 정적·독립 검사, 기존 빌드·자동 시험, 사용자 실행 확인과 당시 미확인 범위를 나누어 작성했다.
- 이번 기록 정리에서 새 Unreal 빌드·자동 시험·PIE·패키징을 실행하지 않았고 게임 코드·에셋 및 발표 파일은 변경하지 않았다.

### 당시 남은 문제 / 미확인 사항

- 각 일지의 남은 작업은 해당 날짜 종료 시점의 상태다. 11월 현재 전체 프로젝트의 완료 상태를 새로 판정한 목록이 아니다.

### 다음 작업 — 당시 기준

- 앞으로 실제 작업한 날짜마다 구현·문제·확인 결과·남은 작업을 이어서 작성하고, 뒤에 해결한 항목은 후속 날짜의 결과로 연결한다.

### 오늘의 기술 정리 (TIL)

- 회고 기록을 복원할 때 작업일, 문서 작성·수정일, 사용자 시험일을 분리해야 계획이 완료 실적으로 바뀌거나 같은 시험이 중복 집계되지 않는다.
